# 记忆维护协议模板

## 1. 结论

记忆维护不是不可验证的后台自动机制，而是一套可审计的文件工作流。

## 2. 触发方式

可靠触发口令：
- 记忆维护
- 同步转生包
- checkpoint
- 更新数字转生文件

## 3. 默认 checkpoint 动作

1. 总结最近对话中的稳定事实、长期偏好、执行原则和边界。
2. 更新本地 Markdown 记忆文件。
3. 更新维护日志，时间精确到秒并包含时区。
4. 执行本地 Git commit（提交快照，用于版本追踪）。
5. 如果 GitHub remote 和认证可用，执行 push（推送到云端备份）。

## 4. 写入标准

允许写入：
- 用户明确确认的事实。
- 用户明确表达的长期偏好。
- 对未来任务有复用价值的边界和协议。

禁止写入：
- 临时闲聊。
- 未确认推测。
- 用户未授权的跨项目、跨对话信息。
