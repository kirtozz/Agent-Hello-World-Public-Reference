为什么不只用一个？因为三者职责不同：

| 如果只用一个文件 | 问题 |
|---|---|
| 把所有信息都塞进 `AGENTS.md` | Agent 每次读到的规则太长，执行重点会被事实细节稀释 |
| 只保留 `USER_PROFILE.md` | 事实很完整，但 Agent 不一定知道哪些是“必须遵守的行为规则” |
| 只保留 `MEMORY_PACKET.md` | 便携，但太压缩，不适合做长期事实源，容易丢细节 |

更工程化地说：

```text
USER_PROFILE.md = 数据源 / Source of Truth
AGENTS.md = 当前项目运行规则 / Runtime Instructions
MEMORY_PACKET.md = 对外迁移包 / Portable Export
```

关于作用范围，最关键：

| 文件 | 当前范围 |
|---|---|
| 当前项目里的 `AGENTS.md` | **只对这个项目目录及其子目录生效** |
